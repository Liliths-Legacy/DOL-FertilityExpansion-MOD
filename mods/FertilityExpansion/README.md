# 生育拓展（FertilityExpansion）

这是面向 DoL `0.5.11.9` 的生育与育儿扩展 Mod。

当前 `1.2.0` 版本包括：

- 带版本号的独立 `$eden` 存档结构。
- 自动登记原版 `$children` 中由 PC 生育或使他人怀上的孩子。
- 原版所有育儿室中直接展示的孩子“简介”。
- 每个孩子独立保存的自由文本介绍，并提供单独的编辑入口。
- 发现农场后可购买位于附近的“伊甸园”，初始容量为三人。
- 农场区域的“前往伊甸园”入口使用独立的 30×30 像素地点图标。
- 花费扩建后容量提高到六人。
- 可以按每名孩子支付贝利要求的费用，将孤儿院中的孩子接到伊甸园。
- 伊甸园大厅及育儿室。
- 所有已登记孩子默认依原版出生日期计算年龄天数与成长阶段。
- 鸟、猫、狐狸、狼、牛使用各自的成年速度修正。
- 原版“选项”页内的独立“生育拓展”标签，可设置成年基准天数或禁止自动成年。
- 可选择让之后从孤儿院接回伊甸园的孩子从入园当天按0天重新计算成长年龄，不改写原版出生日期。
- 容貌、体能、智力三项天生属性及安静／活泼性格；体能固定参考非 PC 一方父母，并支持同卵多胞胎的共同底值与小幅个体差异。
- 鸟、猫、狐狸、狼、牛拥有小幅且平衡的天生属性倾向；跨种族回交只应用修正差值，不会逐代重复叠加。
- 住在伊甸园的动物转化孩子从幼儿期起可每日安排三项活动，培养学识、体能、社交与意识。
- 少年期解锁社区学校、私人家教、社会工作和谈话；付费活动在结算时逐项扣费，余额不足时当项不产生效果。
- 好感与安排活动解耦；婴儿期使用原作互动，幼儿期、少儿期、少年期和成年期各有独立互动池。成长阶段的互动按成年年限和种族速度增加好感，成年互动不再改变好感。
- 活动成长会受天生属性、性格、当前技能与成年速度修正，每日 8:00 结算。
- 孩子成年后依次结算失联、离镇上大学后的职业，或留镇职业，也可由玩家选择放生。
- 大学路线默认在成年结算后随机10至30天触发人生来信，也可在设置中改为成年后立即触发；到期来信不会错过，每次进入伊甸园只处理一封，生成成功后可在通讯录重读。
- 生育拓展设置页可配置独立的OpenAI兼容接口，并可按存档编辑人生来信叙事提示词；固定JSON格式不会开放修改，API密钥只保存在当前浏览器中。
- 伊甸园大厅的无上限通讯录，每页展示六名孩子，支持按结算时间、留镇／离镇和待领取汇款排序，并提供聊天占位交互、月度汇款和亲密邀请检定。
- 通讯录卡片以“天性”和“特质”展示评级与数值，好感位于特质末尾；卡片另有可编辑简介、成年去向及可用的人生来信入口，成年天数收进独立的孩子信息页。
- 亲密邀请成功后可进入原作自愿人形遭遇战，成年孩子的战斗 NPC 与童贞状态会持久保存。
- 独立的成年孩子战斗语录文件，支持按好感、性格、种族和战斗情境自行扩写。
- 战斗语录可按亲缘关系称 PC 为“妈妈”或“爸爸”，不受 PC 当前生理性别影响。
- 成年孩子与 PC 双向受孕：概率、避孕、生育类型和胎数沿用原作规则。
- 成年孩子的孕期在通讯录中持续推进并显示，足月后在伊甸园触发生产。
- 非 PC 一方生产时整胎分配：空位足够则全员进入伊甸园，否则全员进入贝利孤儿院。
- 回交后代的天生属性以成年孩子为基准波动，同卵多胞胎继续共享底值并保留小幅个体差异。
- 受孕提示、孕期信息和新生儿父母字段会显示成年孩子的姓名，内部仍使用稳定编号维持亲缘绑定。

大模型人生来信已有可用的默认Prompt、存档内自定义叙事要求和固定格式保护。尚未加入成年后的专属聊天文本。

- `game/eden.twee`：状态迁移、孩子同步、简介编辑界面。
- `game/eden-age.twee`：选项页中的生育拓展成长设置。
- `modules/eden-profile.js`：向原版孩子列表动态加入简介，不依赖发行版语言。
- `modules/eden-age.js`：基于出生日期、种族与模组设置计算成长阶段。
- `modules/eden-options.js`：在原版选项浮层中加入生育拓展标签，兼容中文发行版的覆盖顺序。
- `modules/eden-traits.js`：一次性生成并保存孩子的天生属性、性格与体能来源。
- `modules/eden-training.js`：养成数值、每日安排、重复计划与结算逻辑。
- `game/eden-training.twee`：活动安排页面。
- `modules/eden-interactions.js`：分阶段互动池、互动分类、好感数值、四小时刷新与成长时间修正。
- `game/eden-interactions.twee`：幼儿、少儿、少年互动状态、按钮及结果正文。
- `modules/eden-adult.js`：好感、成年结算、职业、汇款与亲密邀请检定。
- `modules/eden-llm.js`：OpenAI兼容接口、浏览器配置存储、连接测试和设置界面。
- `modules/eden-life-story-prompt.js`：大学人生来信的Prompt，后续主要在此打磨。
- `modules/eden-life-story.js`：立即或随机10至30天触发、队列、快照、生成状态、结果校验与存档。
- `modules/eden-breeding.js`：成年孩子孕期持久化、生产分流和回交亲缘标记。
- `game/eden-adult.twee`：成年谈话、结果和通讯录页面。
- `game/eden-life-story.twee`：来信发现、生成、阅读和收尾页面。
- `game/eden-encounter.twee`：成年孩子的自愿遭遇战流程。
- `game/eden-encounter-dialogue.twee`：可独立编辑的战斗语录。
- `game/eden-facility.twee`：购房、扩建、育儿室及贝利交涉流程。
- `modules/eden-location.js`：向农场区域加入伊甸园入口。
- `modules/css/eden.css`：界面样式。
- `boot.json`：版本、前置及原版界面注入位置。

构建：

```shell
uv run main.py build
```

构建并启动测试游戏：

```shell
uv run main.py dev --open
```

打包结果位于 `results/FertilityExpansion.mod.zip`。

## 从 Eden 旧版本更新

模组现已更名为「生育拓展 / FertilityExpansion」。安装新版前，请在 Mod 管理器中移除旧的 Eden 模组，避免重复加载。内部存档字段和段落标识保持兼容，游戏内地点仍叫「伊甸园」。
