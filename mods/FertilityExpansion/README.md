## 功能与开发说明

当前 `1.6.0` 版本包括：

- 成年孩子聊天：独立的经历与会话模型、身份卡与人设卡、经历记忆和聊天记录；回复按字数延迟逐句显示，玩家每次发送推进游戏内一分钟。

- 带版本号的独立 `$eden` 存档结构。
- 自动登记原版 `$childRecords` / `$pregnancies` 中由 PC 生育或使他人怀上的孩子。
- 原版所有育儿室中直接展示的孩子“简介”。
- 每个孩子独立保存的自由文本介绍，并提供单独的编辑入口。
- 发现农场后可购买位于附近的“伊甸园”，初始容量为三人。
- 农场区域的“前往伊甸园”入口使用独立的 30×30 像素地点图标。
- 花费扩建后容量提高到六人。
- 可以按每名孩子支付贝利要求的费用，将孤儿院中的孩子接到伊甸园。
- 伊甸园大厅及育儿室。
- 所有已登记孩子默认依原版出生日期计算年龄天数与成长阶段。
- 鸟、猫、狐狸、狼、牛使用各自的成年速度修正。
- 原版“选项”页内的独立“生育拓展”标签，可设置成年基准天数或禁止自动成年。
- 可选择让之后从孤儿院接回伊甸园的孩子从入园当天按0天重新计算成长年龄，不改写原版出生日期。
- 容貌、体能、智力三项天生属性及安静／活泼性格；体能固定参考非 PC 一方父母，并支持同卵多胞胎的共同底值与小幅个体差异。
- 鸟、猫、狐狸、狼、牛拥有小幅且平衡的天生属性倾向；跨种族回交只应用修正差值，不会逐代重复叠加。
- 住在伊甸园的动物转化孩子从幼儿期起可每日安排三项活动，培养学识、体能、社交与意识。
- 少年期解锁社区学校、私人家教、社会工作和谈话；付费活动在结算时逐项扣费，余额不足时当项不产生效果。
- 好感与安排活动解耦；婴儿期使用原作互动，幼儿期、少儿期、少年期和成年期各有独立互动池。成长阶段的互动按成年年限和种族速度增加好感，成年互动不再改变好感。
- 活动成长会受天生属性、性格、当前技能与成年速度修正，每日 8:00 结算。
- 孩子成年后依次结算失联、离镇上大学后的职业，或留镇职业，也可由玩家选择放生。
- 大学路线默认在成年结算后随机10至30天触发人生来信，也可在设置中改为成年后立即触发；到期来信不会错过，每次进入伊甸园只处理一封，生成成功后可在通讯录重读。
- 生育拓展设置页可配置独立的OpenAI兼容接口，并可按存档编辑人生来信叙事提示词；固定JSON格式不会开放修改，API密钥只保存在当前浏览器中。
- 伊甸园大厅的无上限通讯录，每页展示六名孩子，支持按结算时间、留镇／离镇和待领取汇款排序，并提供聊天占位交互、月度汇款和亲密邀请检定。
- 通讯录卡片以“天性”和“特质”展示评级与数值，好感位于特质末尾；卡片另有可编辑简介、成年去向及可用的人生来信入口，成年天数收进独立的孩子信息页。
- 亲密邀请成功后可进入原作自愿人形遭遇战，成年孩子的战斗 NPC 与童贞状态会持久保存。
- 独立的成年孩子战斗语录文件，支持按好感、性格、种族和战斗情境自行扩写。
- 战斗语录可按亲缘关系称 PC 为“妈妈”或“爸爸”，不受 PC 当前生理性别影响。
- 成年孩子与 PC 双向受孕：概率、避孕、生育类型和胎数沿用原作规则。
- 成年孩子的孕期在通讯录中持续推进并显示，足月后在伊甸园触发生产。
- 非 PC 一方生产时整胎分配：空位足够则全员进入伊甸园，否则全员进入贝利孤儿院。
- 回交后代的天生属性以成年孩子为基准波动，同卵多胞胎继续共享底值并保留小幅个体差异。
- 受孕提示、孕期信息和新生儿父母字段会显示成年孩子的姓名，内部仍使用稳定编号维持亲缘绑定。

`1.5.13` 修复了多模组脚本拼接时的启动错误：所有模块增加前置分号，避免前一个模组省略末尾分号时导致“is not a function”，继而使 `EdenChildData` 未初始化并触发 `syncRegistry` 报错。安装时替换旧版生育拓展包，再重新载入游戏。

`1.5.14` 增加原版已转换存档的恢复路径：先载入旧存档、之后才更新模组的玩家，也可由剩余父母表、子女计数、受孕日期和同卵分组重新关联伊甸园资料。恢复同时保留培养进度、亲缘、来信及成年孕期，避免重复转换或生成同一胎。资料不足以确认时保留原记录并提示使用升级前备份。

`1.5.15` 将孩子资料模块独立提前加载，避免普通合并脚本中较早的异常阻止它初始化。侧栏在功能模块缺失时显示当前版本及未加载功能，暂停资料登记、恢复和养成结算；成长设置也保留原值。另修复原版横幅图片的异步回调：使用开始加载时的画布，跳过已经离开页面的旧画布，避免场景切换时 `Weather.banner` 被重置后读取 `skybox` 报错。安装时移除旧版或重复的生育拓展／Eden 包，确认模组管理器显示 `1.5.15`，再完整重启游戏。

`1.5.16` 将 18 个普通模块分别交给 SugarCube 执行，避免前置模组脚本抛错后伊甸园整组功能无法初始化。独立加载发生在模组加载完成、游戏读取脚本之前，保留原来的游戏初始化时机、SugarCube 接口和界面事件注册。孩子资料和存档保护继续有效；加载不完整时的提示不再直接归因为重复安装。替换旧包，确认管理器显示 `1.5.16`，再完整重启游戏。其他模组本身的错误仍需由对应模组处理。

`1.6.0` 加入成年孩子的大模型聊天与经历记忆，支持独立接口配置和可编辑人物卡；孩子回复逐句延迟显示，玩家每次发送推进一分钟，发送按钮位于输入框右下方。安装时替换旧包，确认管理器显示 `1.6.0`，再完整重启游戏。人生来信继续保留默认Prompt、自定义叙事要求和固定格式保护。

- `game/eden.twee`：状态迁移、孩子同步、简介编辑界面。
- `game/eden-age.twee`：选项页中的生育拓展成长设置。
- `modules/eden-profile.js`：向原版孩子列表动态加入简介，不依赖发行版语言。
- `modules/eden-age.js`：基于出生日期、种族与模组设置计算成长阶段。
- `modules/eden-child-data.js`：统一访问旧 `$children` 和新版 `$childRecords` / `$pregnancies`，处理编号 0、出生状态、父母、日期、地点和同卵分组。
- `modules/eden-script-loader.js`：在游戏启动前将伊甸园普通模块拆为独立执行单元，保留游戏初始化时机及接口作用域。
- `modules/eden-runtime.js`：检查侧栏所需功能是否加载完整，并提前修补原版横幅图片异步回调的画布引用。
- `modules/eden-facility.js`：统一检查转移资格、入住容量及贝利费用，写回原版地点，并处理入园时的成长重置与养成起点。
- `modules/eden-options.js`：在原版选项浮层中加入生育拓展标签，兼容中文发行版的覆盖顺序。
- `modules/eden-traits.js`：一次性生成并保存孩子的天生属性、性格与体能来源。
- `modules/eden-training.js`：养成数值、每日安排、重复计划与结算逻辑。
- `game/eden-training.twee`：活动安排页面。
- `modules/eden-interactions.js`：分阶段互动池、互动分类、好感数值、四小时刷新与成长时间修正。
- `game/eden-interactions.twee`：幼儿、少儿、少年互动状态、按钮及结果正文。
- `modules/eden-adult.js`：好感、成年结算、职业、汇款与亲密邀请检定。
- `modules/eden-llm.js`：OpenAI兼容接口、浏览器配置存储、连接测试和设置界面。
- `modules/eden-life-story-prompt.js`：大学人生来信的Prompt，后续主要在此打磨。
- `modules/eden-life-story.js`：立即或随机10至30天触发、队列、快照、生成状态、结果校验与存档。
- `modules/eden-breeding.js`：成年孩子孕期持久化、生产分流和回交亲缘标记。
- `modules/eden-save-migration.js`：0.5.12 原版存档转换期间捕获孩子编号映射，迁移伊甸园资料、亲缘引用和已保存的孕期；失败时回滚。
- `modules/eden-save-recovery.js`：在原版已转换的存档中核对子女计数、日期、旧登记及孕期副本，重建旧编号映射；不直接改写存档。
- `game/eden-adult.twee`：成年谈话、结果和通讯录页面。
- `game/eden-life-story.twee`：来信发现、生成、阅读和收尾页面。
- `game/eden-encounter.twee`：成年孩子的自愿遭遇战流程。
- `game/eden-encounter-dialogue.twee`：可独立编辑的战斗语录。
- `game/eden-facility.twee`：购房、扩建、育儿室及贝利交涉流程。
- `modules/eden-location.js`：向农场区域加入伊甸园入口。
- `modules/css/eden.css`：界面样式。
- `boot.json`：版本、前置及原版界面注入位置。

构建：

```shell
uv run main.py build
```

构建并启动测试游戏：

```shell
uv run main.py dev --open
```

打包结果位于 `results/FertilityExpansion.mod.zip`；每次构建还会生成一个只带版本号的历史包，例如 `FertilityExpansion-v1.6.1.mod.zip`。版本号取已有最高包的第三段并自动加一。

## 从 Eden 旧版本更新

模组现已更名为「生育拓展 / FertilityExpansion」。安装新版前，请在 Mod 管理器中移除旧的 Eden 模组，避免重复加载。内部存档字段和段落标识保持兼容，游戏内地点仍叫「伊甸园」。

## 0.5.12 存档迁移开发

已加入旧存档自动转换机制：在原版转换孩子数据时同步关联伊甸园记录，保留简介、属性、养成、好感、成年去向、来信和亲缘关系，并转换模组保存的孕期。成功后保存一次性标记与旧资料备份；关联不完整或数据冲突时恢复转换前的数据。

已由原版转换并另存、但没有模组编号映射的档会自动尝试恢复：旧父母表、计数及伊甸园旧登记完整，日期与同胎顺序无冲突时，重建对应并继续迁移。模组仍保存完整旧胎儿的成年孕期可转换或复用原版已转换副本。缺少父母表、存在计数缺口或升级后新增孩子、无法区分同日独立孕期、原版在途胎儿已丢失旧编号等情况会保留资料并提示使用升级前备份。

开发目标及安装包的游戏版本声明已切换到 `0.5.12.13`。构建校验直接读取所配置的本地游戏 HTML，检查游戏版本及注入锚点，无需先下载源码；`source` 命令的源码下载版本也锁定为 `0.5.12.13`。

孩子数据访问层、育儿转移、养成安排与每日结算、成年判定及结算已接入新旧两种结构。转移会重新检查容量与费用，年龄重置不修改原版出生日期，成年前最后一天的养成只结算一次。

通讯录、孩子信息与简介页、人生来信也已适配。父母及知情状态读取新孕期记录，出生/产卵/收养日期使用原版游戏日期转换，来信支持编号 0，并保留历史正文与生成快照。孕期跟踪、原版生产接口、亲缘与属性遗传、整胎安置、失败回滚及鸟蛋孵化也已适配。原版页面注入、互动/睡眠入口、孕期解锁设置和格威岚特殊接触规则已完成新版适配，构建时按目标版本选择注入配置。当前安装包使用 7 条新版注入规则，旧版规则保留在源配置中用于历史接口验证。开发说明见仓库 `docs/0.5.12-child-data.md`、`docs/0.5.12-growth-adaptation.md`、`docs/0.5.12-contacts-adaptation.md`、`docs/0.5.12-pregnancy-adaptation.md`、`docs/0.5.12-passage-adaptation.md`；当前验证结果见 `docs/0.5.12-release-validation.md`。
