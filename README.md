# 生育拓展（FertilityExpansion）

本模组为DOL生育相关的玩法扩展。
在原版的基础上为DOL添加了育种与养成玩法。

## 内容

- 怀孕扩展：
  - （v1.2.0更新）添加一个可选选项，可开放原版中代码绝育的贝利、礼顿、格威岚的受孕与授孕限制；
- 生育扩展：
  - 为所有宝宝添加了可供编辑和展示的简介，可用来记录宝宝的来源与故事；
  - 为所有宝宝添加了五种带有遗传倾向的天生属性；
  - （进行部分属性检定之后）可与成年**动物转化后代**回交来获得更加定向的后代；
- 养育扩展
  - 在农场旁添加了一个专门用于养育孩子的安全屋（升级项目正在开发中）
  - 增加了从孤儿院育儿室带走孩子的选项，可通过向贝利支付金钱带走孩子；
  - 为**动物转化宝宝**添加了四种可养成的后天技能，以及好感度；
  - 为**动物转化宝宝**添加了三个成长阶段和相应的互动；
  - 为**动物转化宝宝**添加了【安排活动】功能，以获得技能属性增长；
  - 为**动物转化宝宝**添加了多种成年结局；
  - （v1.2.0更新）为满足“离开小镇”条件的孩子增加了【人生来信】功能，可配置大模型生成ta离开之后的故事；* 备注：故事生成基于孩子属性与简介内容，并可通过备注修改大模型提示词以调整文风倾向。
  - （v1.3.0更新）增加了从鹰塔/狼洞/农场育儿室带**人形宝宝**（包括动物转化与怪物人形，不包括纯鹰崽与狼崽）至伊甸园的入口；
  - （v1.4.0更新）增加了允许培养人类宝宝的开关。

当前更新到1.5.10版本，功能仍在开发中。

## 未来开发计划：
- 育种与养成数值优化；
- 更多的结局与养成项目；
- 更多与成年孩子的互动；

- 考据命名NPC的各项属性，为命名NPC设置可遗传的属性数值基准。

## 下载与安装

在本仓库的 [Releases](https://github.com/Liliths-Legacy/DOL-FertilityExpansion-MOD/releases) 下载 `FertilityExpansion.mod.zip`，通过游戏的 Mod 管理器添加，然后重新载入游戏。无需解压模组包。

- 适配游戏版本：DoL `0.5.11.9`。
- 前置：ModLoader `^2.101.0`、TweeReplacer `^1.7.0`；本地测试使用 ModLoader `2.101.1`。
