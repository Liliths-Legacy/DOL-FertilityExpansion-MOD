# 生育拓展（FertilityExpansion）

本模组为DOL生育相关的玩法扩展。
在原版的基础上为DOL添加了育种与养成玩法。

## 内容

- 怀孕扩展：计划中
- 生育扩展：
  - 为所有宝宝添加了可供编辑和展示的简介，可用来记录宝宝的来源与故事；
  - 为所有宝宝添加了五种带有遗传倾向的天生属性；
  - （进行部分属性检定之后）可与成年**动物转化后代**回交来获得更加定向的后代；
- 养育扩展
  - 在农场旁添加了一个专门用于养育孩子的安全屋（升级项目正在开发中）
  - 增加了从孤儿院育儿室带走孩子的选项，可通过向贝利支付金钱带走孩子；
  - 为**动物转化宝宝**添加了四种可养成的后天技能，以及好感度；
  - 为**动物转化宝宝**添加了三个成长阶段和相应的互动；
  - 为**动物转化宝宝**添加了【安排活动】功能，以获得技能属性增长；
  - 为**动物转化宝宝**添加了多种成年结局；

当前为0.8版本，功能仍在开发中。

## 未来开发计划：

## 下载与安装

在本仓库的 [Releases](https://github.com/Liliths-Legacy/DOL-FertilityExpansion-MOD/releases) 下载 `FertilityExpansion.mod.zip`，通过游戏的 Mod 管理器添加，然后重新载入游戏。无需解压模组包。

- 适配游戏版本：DoL `0.5.11.9`。
- 前置：ModLoader `^2.101.0`、TweeReplacer `^1.7.0`；本地测试使用 ModLoader `2.101.1`。
- 从旧版 Eden 更新时，先移除旧的 Eden 模组，避免同时加载；内部存档字段保持兼容。
- 游戏本体、原版图片及前置模组需另行准备。

## 本地开发

模组源码位于 `mods/FertilityExpansion/`。

1. 安装 Python 3.10 或以上版本及 uv，在仓库根目录执行 `uv sync`。
2. 将 DoL `0.5.11.9` 原版源码放入 `degrees-of-lewdity-0.5.11.9/`，确保其中包含 `game/`。
3. 准备包含 ModLoader 的游戏发行版和 `img/`，在 `configs/dev.json` 中设置 `runtime_dir` 和 `html`。相对路径从仓库根目录解析。
4. 在仓库根目录执行 `uv run main.py build`，生成 `results/FertilityExpansion.mod.zip`。
5. 执行 `uv run main.py dev --open` 可构建并启动本地测试游戏。

当前构建校验需要同时准备原版源码和游戏发行版。
