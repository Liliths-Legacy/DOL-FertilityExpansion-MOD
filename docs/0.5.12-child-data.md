# 0.5.12 孩子数据访问层

> 当前开发目标与最终验证结果见 [0.5.12.13 验证记录](0.5.12-release-validation.md)。下文保留该步骤完成时的状态与范围。

实现：`mods/FertilityExpansion/modules/eden-child-data.js`，普通脚本加载，公开 `window.EdenChildData`。游戏版本声明仍为 0.5.11.9，当前完成的是完整适配的公共基础。

## 数据来源与身份

每次调用读取当前 SugarCube State，避免读档、撤销后使用旧引用。存在原版 `$childRecords` 数组时使用新结构，即使数组为空也不回退到遗留 `$children`。没有该数组时使用旧孩子字典，旧编号按完整字符串精确查找。

新版编号是数组索引，数字 `0` 和字符串 `"0"` 都合法。空值、布尔值、小数、负数、非规范数字字符串不作为新编号使用。列表不压缩原版数组，也不重新编号。

查询返回原版对象引用。`collection()` 仅生成临时字典，不把新记录复制到存档里的 `$children`，不生成第二份可变孩子资料。读档后应重新查询，不能长期持有返回对象。

## 公共接口

| 接口 | 用途 |
| --- | --- |
| `get(id, vars?)` | 读取原版孩子对象，找不到返回 `undefined` |
| `entries({scope, location}?, vars?)` | 返回 `[编号字符串, 原版对象]` 列表 |
| `collection(options?, vars?)` | 将同一列表整理为临时字典，值仍是原版引用 |
| `pregnancyOf(child, vars?)` | 新版孩子关联的原版孕期；旧版或缺失返回 `null` |
| `phaseOf(child, vars?)` | `born`、`egg`、`unborn`、`removed` 或 `missing` |
| `parentsOf(child, vars?)` | `mother` / `father` 及玩家是否知道其身份 |
| `baseSpecies(child)` / `typeOf(child)` | 基础种族 / 兼容旧读者的人形或动物类型 |
| `isAdopted(child)` | 是否有领养日期，日期编号 0 也有效 |
| `locationOf(child)` / `setLocation(child, location, vars?)` | 读取地点 / 直接写回原版地点 |
| `bornOf(child)` / `conceivedOf(child, vars?)` | 出生或受孕的 `{year, month, day}` 日历日期；无日期返回 `null` |
| `laidOf(child, vars?)` / `adoptedOf(child)` | 产卵或收养日历日期，无日期返回 `null` |
| `developmentOf(child)` | 新版 `development` 或旧版 `localVariables`，缺失返回空对象 |
| `ageDays(child, record?, vars?)` | 伊甸园成长年龄，遵守转移重置起点 |
| `identicalGroup(child)` / `isIdentical(child)` | 同卵组标记 / 是否同卵；组编号 0 有效 |
| `syncRegistry(eden, vars?)` | 将属于玩家或被领养的世界孩子登记到伊甸园 |

`scope` 默认 `world`，包括已出生孩子与已产下未孵化的蛋，与原版 `getBornChildren()` 的正常记录范围一致。其他可选值是 `born`、`egg`、`unborn`、`all`；`all` 也排除已清除的孕期记录。未出生胎儿不能通过地点接口转移，不会自动登记成育儿对象。

新版父母来自孕期 `carrier` / `donor`，知情状态来自 `awareOfCarrier` / `awareOfDonor`。新版地点写入 `development.location`，保留互动次数、活动状态等其他字段。查询父母不会因为玩家尚未知情而丢失真实身份，界面应另行判断知情标记。

原版新日期是游戏从公元 1 年开始累计的秒数，使用原版 `DateTime` 转换，不能当作 Unix 毫秒。年龄延续伊甸园原有的日历天差：23:59 出生，翌日 00:01 为 1 天。未孵化的蛋和胎儿成长年龄为 0。`growthStartSerialDay` 仍优先用于转移后重置年龄。

新版同卵分组使用孕期编号和同卵标记，避免不同孕期混组。已有天生属性不会重新生成；同卵组后续登记的孩子可以共用已保存的底值。

## 当前接入范围

`edenSyncChildren` 已改为统一登记，`edenSetup` 中年龄和天生属性同步通过临时孩子字典读取两种结构。`EdenAge` 使用统一日期及类型接口；`EdenTraits` 使用统一父母、类型和同卵接口，并可在新版缺少 `$parentList` 时读取留存 NPC 的体型依据。

育儿转移页面、养成与成年结算已接入，详见 `0.5.12-growth-adaptation.md`。通讯录、信息/简介页与人生来信也已接入，详见 `0.5.12-contacts-adaptation.md`。互动注入和新版孕期推进仍需适配，这些部分目前仍有旧 `$children` 引用，不能据此开放 0.5.12 的发布版本限制。浏览器加载顺序与真实玩家存档回归也留待完整适配阶段。

## 验证

`node --test tests/eden-child-data.test.js` 覆盖新旧身份、编号 0、胎儿/鸟蛋范围、父母知情、领养、地点写回、注册幂等、重置年龄、种族体型、同卵属性保留、读档切换。

原版集成测试从本地 0.5.12.13 HTML 提取 `DateTime` 与孩子查询函数，验证日历跨午夜差异和原版世界/地点查询一致性。可通过 `DOL_0512_HTML` 指定运行文件；缺少 HTML 时仅跳过这些原版集成测试。
