# 0.5.12 旧存档迁移机制

> 当前开发目标与最终验证结果见 [0.5.12.13 验证记录](0.5.12-release-validation.md)。下文保留该步骤完成时的状态与范围。

实现位于 `mods/FertilityExpansion/modules/eden-save-migration.js`，由 `boot.json` 的 `scriptFileList_inject_early` 加载。游戏版本声明仍锁定 0.5.11.9；本次只加入数据迁移，完整 0.5.12 适配需要继续更新孩子数据访问、互动注入和孕期玩法。

## 执行时机

早期脚本在 `twine-user-script` 中为原版 `migratePregnancyData()` 增加事务包装：

1. 在原版删除旧 `$children` 之前取得原版 `oldKeyToNewId` 的准确映射，不按姓名、相貌或模组记录顺序推断。
2. 原版转换 PC / NPC 在途胎儿时，保存胎儿旧编号与自定义亲缘标记。
3. 原版转换成功后，将 `$eden.children` 重建为以新编号字符串为键的字典。原版编号仍是数字；模组编号使用字符串，因此首个孩子为 `"0"`。
4. 更新模组选择、亲缘、生产记录、成年事件和持久 NPC 引用，转换模组自存孕期。
5. 写入 `$eden.recordsMigration` 完成标记、准确映射和旧资料备份。

如果原版迁移结构改变，无法捕获完整映射，就终止转换并回滚。0.5.11 没有对应迁移函数，早期脚本不修改其游戏代码。

## 保留与重写的字段

保留原值：简介、天生属性、好感、技能、活动日程、结算日期、重置成长起点、职业与去向、汇款状态、已生成来信和历史生成快照。迁移不调用属性生成、成长结算、生产或大模型服务。

重写身份引用：`childId`、选择指针、爬床事件指针、`geneticParentId`、`inheritedFrom`、孕期与生产父母指针、`childIds`、`parentsByDescription`，以及身份字段里的 `Eden child <旧编号>` / `eden_child:<旧编号>`。

更新 `$per_npc` 键、当前 `$NPCList` 和 `$storedNPCs` 的身份信息，保留事件次数和持久角色状态。更新原版新怀孕记录的父母、知情和候选父母身份；出生孩子与未出生胎儿的自定义亲缘标记同步恢复。

自由文本不会被全局字符串替换，已生成来信和 `inputSnapshot` 是历史内容，原样保留。

## 模组自存孕期

旧 `$eden.children[id].adult.pregnancy.fetus / timer / timerEnd` 转换为原版 `$pregnancies` 与 `$childRecords`。使用原版 `inflightConceivedDate()` 按既有进度计算新受孕时间，不重新抽取胎数、性别或外貌，也不提前生产。

转换后的 `adult.pregnancy` 是版本 2 的引用描述：

```js
{
    edenDataVersion: 2,
    pregnancyId: 0,                 // 原版怀孕记录索引，0 合法
    edenParentChildId: "0",         // 孕期所属的模组成年角色
    givenBirth: 0,
    totalBirthEvents: 0,
    due: false,
    deliveryBlocked: false
}
```

原有生产失败说明也保留。完整旧孕期对象保存在备份中。

如果原版已从 `$storedNPCs` 转换了同一份胎儿，用准确的旧胎儿编号复用该孕期，避免重复生成。该模组孕期改用稳定角色身份，脱离原版随机角色的自动生产调度；后续新版伊甸园生产功能需按这个引用处理它。

## 完成、失败与恢复

成功：`recordsMigration.version = 1`、`status = "complete"`；重载不再次转换。`childMap` 的值为数字；`legacyBackup.eden` 保存迁移前的模组资料，`legacyBackup.children` 保存迁移前的原版已出生孩子 / 已产下鸟蛋。

失败：原版与模组数据作为一个事务恢复。完成标记不写入，保存 `version = 0`、`status = "failed"` 与错误说明，修复后仍可重试。失败恢复不会写入浏览器原有存档槽。

原版已转换、但缺少准确映射的存档：`ensureReady()` 将状态设为 `needsRecovery`，保留未匹配记录并暂停伊甸园同步，页面提示使用升级前备份。没有可靠依据时不推测编号。

资料为空且没有遗留身份引用的新存档直接标记为新结构。仅孩子列表为空、仍有遗留事件指针的档不被当作新存档。

## 验证

运行 `node --test tests/eden-save-migration.test.js`。测试包括准确映射、编号 0、同名 / 同卵、未出生胎儿、鸟蛋、亲缘、持久角色、模组孕期、重复载入、失败回滚、重试与缺失映射保护。

集成测试直接从本地 0.5.12.13 HTML 提取原版记录和迁移函数；可通过 `DOL_0512_HTML` 指定其他测试 HTML。缺少 HTML 时只跳过这些原版集成测试，基础迁移测试仍执行。

本地还检查完整游戏用户脚本经早期修补后能够解析。浏览器最终加载顺序及玩家真实存档需在完整 0.5.12 适配时进一步回归。
