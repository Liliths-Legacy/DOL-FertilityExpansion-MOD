# 0.5.12 孕期与生产适配

> 当前开发目标与最终验证结果见 [0.5.12.13 验证记录](0.5.12-release-validation.md)。下文保留该步骤完成时的状态与范围。

本次完成适配清单第 4 项。`EdenBreeding` 同时支持旧版胎儿列表与新版原生记录；`edenSetup`、通讯录孕期卡片、生产页和接触流程入口已接入新版孩子查询。游戏发布声明仍保持 0.5.11.9，其他原版页面注入和设置接口尚待后续调整。

## 受孕与亲缘记录

在原版用户脚本执行和宏注册前，`eden-birth-bridge.js` 对 0.5.12 的受孕入口作局部修补。先验证全部源代码锚点，再一次性修改；锚点改变时不写入部分补丁，状态为 `unsupported-records`。旧版仍只导出其原生生产函数。

修补仅匹配有真实孩子记录、已成年结算、可识别为人形且使用准确稳定身份的伊甸园角色。受孕仍由原版判断概率、受孕禁用条件、不孕条件及玩家/NPC相关设置；普通生成 NPC 沿用原版的随机保留和人数限制。伊甸园角色受孕成功后使用 `Eden child <id>` 作为 carrier，不加入原版随机 NPC 自动生产队列。人形狼人和鸟人的种族不再被普通人类遭遇入口统一当作 human；原版生成后代时也能读取伊甸园父母真实的性别和外貌颜色。

伊甸园保存的 `adult.pregnancy` 是版本 2 的引用描述，包含原版 `pregnancyId`、伊甸园父母编号和失败/到期状态，不另存胎儿副本或计时器。原版 `$pregnancies` 与 `$childRecords` 保存受孕日期、胎数、种族、性别、外貌和同卵关联。怀孕编号 0、孩子编号 0 均有效。

玩家作为孕育方时，使用孕期的真实 donor 关联伊甸园遗传父母，涵盖即时受孕与原版延迟受孕后生成的记录，不根据候选父母名单猜测。关联本身不会修改原版知情标记，未知父母仍按原版规则显示。生产后将亲缘关联写入伊甸园记录，先于属性生成，从而继续使用原有遗传属性规则。

旧原版随机 NPC 队列中已有的伊甸园孕期会按准确稳定身份接管，保留原怀孕及胎儿编号，并移出自动生产队列。上一阶段迁移生成的版本 2 描述也直接进入本流程。

## 孕期、生产与安置

孕期状态与到期时间直接读取原版 `pregnancyProgress()`、`getDueDate()`，包括孕期长度设置、随机孕期差异和鸟蛋照料缩短的时间；伊甸园不再累加第二份新版孕期计时。未到期、已清除、已生产、父母不匹配或缺失的记录不能生产，失败重试也不能将未到期的孕期强行推进。

到期后调用原版 `birthRecordedLitter()`，沿用原版出生/产卵日期、抚育资料和后代统计。入住容量只计算已出生后代与已产下的蛋，未出生胎儿不占空位。空位足够时整胎进入伊甸园，否则整胎进入孤儿院；不拆分同胎。出生地点按基础种族记录，入住地点独立保存。

生产前复制当前存档状态。原版生产抛错、生成不完整，或伊甸园生产后的结算抛错时，恢复原生记录、抚育资料、姓名、统计和伊甸园状态，并保存失败原因供重试。恢复保留当前页面持有的父母、孕期和孩子对象引用。生产成功后保存本次怀孕编号，重复打开生产页不会重复生产或增加统计；新孕期也不会被上次成功结果掩盖。此事务只保护模组内状态，不回滚第三方插件在生产函数中执行的外部操作。

## 鸟蛋孵化

鸟类后代先记录产卵，`bornDate` 保持 null，通讯录与生产页明确区分生产和产卵。未孵化时不计算出生年龄。

伊甸园或孤儿院中的模组管理鸟蛋，在 `edenSetup` 同步时按原版 `getHatchDate()` 检查孵化；到期后只调用原版命名和 `recordBirth()`，保留现有姓名、抚育地点、互动和收养资料，不重建孩子、不重复增加生产统计。孵化失败会恢复这一批蛋，后续同步可重试。塔楼中的蛋仍由原版孵化页面处理。

`statFreeze` 开启时不结算生产和孵化。

## 验证与限制

`tests/eden-pregnancy-adaptation.test.js` 从本地 0.5.12.13 HTML 提取实际原版孕期、受孕、种族生成和生产函数运行，覆盖宏注册前修补、新旧版本并存、人类/狼人/鸟人、编号 0、原版受孕开关、种族与外貌遗传、玩家亲缘、孕期进度、双胞胎整体安置、容量、生产幂等、失败回滚与重试、产卵与孵化、地点/收养资料保留、冻结，以及与旧存档迁移补丁共存。测试未调用外部服务。可通过 `DOL_0512_HTML` 指定测试 HTML；缺少 HTML 时明确跳过原版集成案例。

这些是脚本和打包验证，尚未完成浏览器加载顺序、汉化显示和玩家真实存档回归。失效的原版段落注入、旧孕期设置接口及已删除的特殊受孕接口仍属于后续适配，本次不代表完整 0.5.12 发布就绪。
