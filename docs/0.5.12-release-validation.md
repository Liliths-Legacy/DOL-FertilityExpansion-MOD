## 构建与运行

- `configs/dev.json` 指向新版运行目录；`src/consts.py` 的源码下载目标同步更新。
- 校验器直接读取该运行目录的实际 HTML，不再要求先下载源码，也不会用 0.5.11 源码校验新版注入。游戏文件版本必须匹配配置，每个替换锚点必须精确命中一次。
- 相对运行路径以项目根目录为基准，启动服务时不依赖当前工作目录。
- 安装包 `results/FertilityExpansion.mod.zip` 选择 7 条新版注入规则，不含构建用 `edenRecords` 元数据，也不注入旧 `Widgets Orgasm` 孕期逻辑。

运行 `uv run main.py build` 构建，`uv run main.py dev --open` 构建并打开本机测试页。`source` 是可选的原版源码下载命令。
