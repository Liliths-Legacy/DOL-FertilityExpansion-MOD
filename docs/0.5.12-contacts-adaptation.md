# 0.5.12 通讯录、信息页与来信适配

> 当前开发目标与最终验证结果见 [0.5.12.13 验证记录](0.5.12-release-validation.md)。下文保留该步骤完成时的状态与范围。

本次完成适配清单第 3 项：通讯录卡片、详细信息、简介列表与编辑页、来信打开/生成/阅读/重读页面均改为通过 `EdenChildData` 查询原版孩子。数字编号 0 与旧复合编号都可以使用。

## 信息显示

父母身份和知情标记从统一父母接口读取；未知身份仍显示 `????`，不会因为存在孕期里的真实身份而提前揭示。伊甸园后代作为父母时，通过稳定身份读取其当前姓名，不按同名记录猜测。

出生、产卵、收养日期使用原版 `DateTime` 转换为日历日期。产卵日期取鸟类孕期的 `deliveredDate`，收养日期取孩子的 `development.adoptedDate`，时间戳 0 有效。未孵化的蛋显示“尚未孵化”，不计算原版出生年龄；缺少日期时显示“不详”。

原版体型、发色、肤色仍使用原版展示控件。新结构不再读取 `child.type`，外观标签按基础种族选择。同卵标记通过统一接口判断，组编号 0 也会显示“同卵：是”。互动总数读取 `development.interactionsTotal`，旧版读 `localVariables.interactionsTotal`，计数 0 可以显示。

通讯录排序、分页、职业与去向标签、汇款计算仍使用伊甸园保存的成年记录。缺少原版孩子时保留通讯录条目并显示无法读取提示，不删除简介或历史来信。

## 来信生成与保存

生成入口改为使用临时原版孩子字典，并修正数字编号 0 的空值判断。新生成快照从真实父母关系判断玩家是母亲、父亲、养父母或家长，避免新版孩子没有顶层 `mother` 导致全部被认为由玩家担任父亲。提示词归一化识别新的 `pcParentRole`，同时兼容旧快照。

已有来信正文、生成快照、日期和模型信息不会重新生成或被新简介覆盖。重试沿用原生成快照，修改当前姓名、简介不会改写历史生成输入。已有来信再次打开不发送新请求，也不重置阅读日期。

每次生成保存独立的 `generationToken`。异步回复只更新当前状态中仍属于这次生成的记录；普通页面切换产生的状态克隆可以继续接收结果，切换到另一个同编号存档时不会覆盖其资料。只在仍打开对应孩子的生成页时自动跳转阅读。旧请求结束不会清掉同编号的新请求，重复打开同一封生成中的来信也不会重复发送。

生成状态随存档保存，但请求本身不保存。刷新后没有活跃请求的“生成中”状态会恢复为可重试错误。此字段无需额外修改旧存档迁移标记。

## 验证与未完成事项

`node --test tests/eden-contacts-adaptation.test.js` 覆盖日期和计数、新旧孩子身份、知情标记、缺失资料、伊甸园父母姓名、排序与分页、汇款幂等、父母关系快照、历史来信保留、编号 0、旧编号生成、重复生成、失败重试、读档、页面切换和请求冲突。来信服务使用测试替身，测试不调用外部模型服务。

打包检查确认信息页与来信页接入新接口。浏览器实际显示、汉化加载顺序和真实玩家存档回归仍待完整适配阶段。孕期状态卡片和生产页属于第 4 项，接触流程及互动注入属于后续适配；本次不代表完整 0.5.12 兼容，发布版本限制仍保留 0.5.11.9。
