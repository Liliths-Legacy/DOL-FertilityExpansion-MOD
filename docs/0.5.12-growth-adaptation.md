# 0.5.12 成长、转移与养成适配

> 当前开发目标与最终验证结果见 [0.5.12.13 验证记录](0.5.12-release-validation.md)。下文保留该步骤完成时的状态与范围。

本次完成适配清单第 2 项。孩子登记、种族体型、日期与同卵规则沿用已完成的数据访问层；入住、养成和成年结算直接读写原版新旧结构。

## 入住与转移

新增 `modules/eden-facility.js`，公开 `window.EdenFacility`：

| 接口 | 行为 |
| --- | --- |
| `residentIds(vars?)` | 列出位于 `eden_home` 的世界孩子；已产下的蛋占用空间，胎儿和已清除孕期不计入 |
| `inspectTransfer(eden, childId, source, vars?)` | 检查资格、出生状态、地点、形态、结算状态、容量与费用，返回状态说明 |
| `move(eden, childId, source, vars?)` | 点击时重新检查并完成入住，返回成功或失败结果 |

来源保留 `home`、`wolf_cave`、`tower`、`alex_cottage`。玩家亲生的人形孩子可以转移；高塔中已领养的人形鸟类孩子也可转移。未孵化的蛋、胎儿、动物形态、非亲生且非高塔领养的孩子、已完成成年结局的角色不允许重新入住。

孤儿院费用仍是 £100,000（10,000,000 游戏货币单位）。扣费集中在成功转移时，优先走原版 `statChange.money`，避免 UI 与逻辑各扣一次。页面渲染后空位、余额、孩子地点变化，点击时会失败并显示原因。重复点击已转移的孩子不会再次扣费或重置成长。

新版地点写入 `development.location`，保留活动、互动次数、领养日期等资料；旧版仍写入 `location`。成功转移后设置入住状态及来源，保存支付标记，清除临时返回列表和转移上下文。

## 年龄与每日养成

开启重置年龄时，仅更新伊甸园 `growthStartSerialDay`，出生日期保持原值。关闭时从出生日期继续成长。新旧结构都保留已生成属性、技能、日程、简介和已有好感；仅缺少好感时初始化为 40。

入住时将养成结算进度推进到当时的结算日，避免长时间未入园的孩子补算入园前的课程或费用。已经保存的未来计划及技能保留。每日结算仍在 08:00，成年当天会先完成最后一次少年期安排，随后进行成年结算；更晚的成年日期不继续增长技能或扣课程费用。多次同步不重复结算。

`edenSetup` 先同步年龄及天生属性，再同步养成，最后同步成年状态。活动安排、设置中的成长同步、装修改动前的养成同步均改用统一孩子列表。养成资格明确要求已经出生、位于伊甸园、属于支持种族且为人形；蛋或胎儿不能通过遗留阶段值绕过检查。

## 成年结算及入口

成年判定及结算读取统一地点和出生状态。成功结算将原版地点更新为 `eden_contacts` 或 `eden_released`，释放入住空间。需要成年结算的角色可通过原版孩子查看器中的按钮进入页面，编号 0 可以打开养成、转移和成年页面。

原版查看器的简介区读取新记录；其中转移按钮、养成按钮及成年按钮使用新版判断。育儿室仍使用原版查看器展示孩子。通讯录与已生成来信详情、后续角色接触、新版孕期、阶段互动注入不是本次范围。

## 验证与未完成事项

运行 `node --test tests/eden-growth-adaptation.test.js`，覆盖两种结构的转移、费用、年龄重置，容量与出生资格，重复同步，每日结算、成年当天四个时点、迟到补算、不会自动成年、成年离园与重复结算、装修生效日、编号 0 的页面入口。集成测试使用本地 0.5.12.13 的原版 `DateTime`，验证重置后完整成长至成年与最后一天结算；缺少运行文件时可用 `DOL_0512_HTML` 指定。

发布声明仍限制在 0.5.11.9，等待通讯录、新版孕期及互动注入适配完成后再调整。浏览器实际加载与真实玩家存档的完整回归尚未完成。
