# 0.5.12 页面注入、互动与孕期设置适配

> 当前开发目标与最终验证结果见 [0.5.12.13 验证记录](0.5.12-release-validation.md)。下文保留该步骤完成时的状态与范围。

本次完成实施顺序第 5 项。第 6 项的开发目标切换、发布声明和浏览器真实存档回归尚未执行。

## 注入配置

源 `boot.json` 在需要区分新旧接口的规则上增加构建用 `edenRecords` 配置。`src/runtime_patches.py` 根据 `configs/dev.json` 的游戏版本选择规则，构建器和校验器使用同一选择函数。旧版规则保留，新版规则不包含旧 `$children`、`recordSperm` 或 `pregnancyGenerator` 调用；构建用字段不进入安装包。

当前开发目标仍为 0.5.11.9，因此常规构建仍输出 9 条旧版兼容规则。切换到 0.5.12 后会输出 7 条规则：

| 入口 | 新版处理 |
| --- | --- |
| StoryCaption | 保留 `edenSetup` 注入，内部已使用统一孩子层 |
| Children Activity Events | 保留原版互动完成锚点，记录接口改用当前孩子查询，编号 0 有效 |
| Widgets children | 按 `$childRecords[id].species` 定位原版活动块；伊甸园阶段活动池之外继续走原版活动 |
| Widgets Sleep | 保留睡眠分流锚点，传入当前孩子集合 |
| Bird Tower | 使用已出生、地点为 tower 的孩子列表；各类后代均可进入查看，蛋和胎儿不计入出生孩子数量 |
| Widgets Combat：牵手 | 在参与者身份和物种已确定的位置接入格威岚特殊规则 |
| Widgets Combat：接吻 | 同上；触发在“是否第一次接吻”的判断之外，后续接触也可触发 |

两条旧 `Widgets Orgasm` 注入在新版构建中移除。伊甸园角色的稳定受孕跟踪、鸟人/狼人种族处理已经由第 4 项早期脚本桥接接管，不重复挂接。

所有选中的规则均在对应的本地 0.5.11.9 / 0.5.12.13 原版 HTML 中精确命中一次。此检查涵盖目标版本选择和替换内容，尚未验证汉化插件实际加载后的最终覆盖顺序。

## 互动与睡眠入口

阶段互动、原版互动记录、睡眠访问页面及遭遇对话均改为 `EdenChildData` 查询，保留旧复合编号，支持新版数字编号 0。模块读新版 `development.location`，未出生胎儿、未孵化蛋和已清除记录不进入阶段互动或成年访问资格。

阶段活动只在当前孩子仍处于伊甸园、活动及成长阶段一致时结算。重复进入结果页不重复增加好感或模组互动计数；转移孩子或改变成长阶段后，旧活动不能再结算。原版互动计数只在模组确认活动成功后增加，既有抚育资料不重置。原来的时间、概率、冷却期和成年资格数值保持原设定。

## 怀孕解锁开关

新版 `hasActivePregnancy()` 从原版 `$pregnancies` 查询真正未生产的孕期，怀孕编号 0 有效。它不依赖 `C.npc[name].pregnancy.enabled` 或残留旧胎儿字段；已生产和已清除记录不视为正在怀孕。旧版仍使用原生旧孕期结构。

设置页复选框的明确 false 优先于尚未同步的 `$eden.settings`，避免用户关闭后被旧设置值重新开启。关闭时，只为当前孕育中的命名 NPC 暂时保留孕期支持，原有孕期记录、进度和配置不重建；生产后恢复原始限制。玩家已经形成的孕期不被此开关删除。

模块记录自身修改前的名单状态，恢复时保留其他模组原先已提供的支持及无关角色。重复同步不重复添加名单，也不重复调用原版配置更新器；配置更新器暂不可用时延后执行。

## 格威岚特殊规则

0.5.12 不再提供旧 `silly` 模式或旧 `fetishPregnancy()`。新版规则为：开启“不准绝育”，处于原版 `fetish`（奇幻怀孕）模式，与 Gwylan 裸手牵手或无遮挡接吻时，可在具备相应生理条件的方向尝试受孕。其他角色或其他接触不触发此规则。

玩家孕育方向使用原版 `sceneInseminate()` 的即时受孕路径，不保存持久载荷；Gwylan 孕育方向使用原版 `npcPregnancyRoll()`。原版概率、周期、药物、物种开关、命名 NPC 怀孕开关、身体条件及特殊部位怀孕开关均继续生效，不强制创建孕期。生成角色怀孕开关与命名 NPC 开关区分处理。已有同方向孕期不会重复生成。

梦境、受孕禁用状态、冻结、手套或遮脸服装会阻止对应触发。真实模式不触发此特殊规则。旧版仍保留童话模式和原来的函数调用及概率修正；新版改用新版的受孕概率模型，不搬入旧公式。设置说明已同步更新。

## 验证与后续

`tests/test_runtime_patches.py` 检查版本选择、构建字段去除、新旧发行版每条锚点精确匹配，以及剩余页面的数据查询。

`tests/eden-passage-adaptation.test.js` 检查开关关闭与已有孕期保护、名单恢复、重复同步、延期初始化、裸手/无遮挡条件、新旧特殊规则、编号 0、互动幂等、移动/成长后的旧事件、胎儿/蛋排除和成年睡眠入口。新版特殊规则直接运行本地 HTML 提取的原版受孕、药物、物种及胎儿生成函数；UI 配置更新器使用测试替身。

下一步应切换到 0.5.12 开发目标，让安装包实际选择新版规则，再检查浏览器最终加载顺序、汉化显示与真实旧存档。当前安装包仍受 0.5.11.9 版本声明限制，不应作为完整 0.5.12 发布包。
